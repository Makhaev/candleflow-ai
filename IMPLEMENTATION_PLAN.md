# План нормализации CandleFlow

Исходная версия сохранена в Git. Требования к схеме и REST API дополняют ранее проверенные сценарии склада и ассистента.

| Этап | Критерии приёмки | Результат |
| --- | --- | --- |
| Учёт | Справочники, заголовки поступлений, котировки, ограничения, индексы, журнал движений, перенос старых данных | Выполнено. Журнал сверяется с физическим остатком и резервом. Перенос проверен на копии прежней БД. |
| Ассистент | Таблицы вызовов, файлов, памяти, псевдонимов. Диалоги и ожидающие действия сохраняются. | Выполнено. На копии проверен цикл перехода с 0004, отката и повторного применения. |
| REST и OpenAPI | Схемы запросов, ответов и ошибок. Ресурсы поступлений, истории и отдельные операции жизненного цикла. | Выполнено. Проверены cookie-аутентификация, лимиты, SSE и схемы файлов. Swagger открыт через локальный API. |
| Проверка | PostgreSQL, Alembic, Ruff, ESLint, сборка, эталонный прогон и README | Выполнено. 26 тестов и 12 эталонных сценариев прошли. Схема актуальна, миграции применены и на пустую БД. |

У старой схемы не было идентификатора поступления. Каждый старый лот получил отдельное поступление, а новые лоты группируются по реальному документу. Журнал для старых партий начинается с перенесённого баланса. Прежние изменения сохранены в аудите. В README описаны остатки, перерасход, точность и округление.

Запуск Compose и живой OpenAI требуют Docker и ключа соответственно. Проверки этой версии выполнены с локальным PostgreSQL и fake-провайдером.
