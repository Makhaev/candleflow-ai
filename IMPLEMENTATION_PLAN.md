# План UI CandleFlow

Предыдущая версия сохранена в Git. Номера партий, заданий и диалогов привязаны к данным PostgreSQL.

| Этап | Критерии приёмки | Результат |
| --- | --- | --- |
| API ролей и аудита | Переключение выдаёт новую сессию реальной учётной записи. Общий аудит доступен руководителю. Фильтры и пагинация на сервере. | Выполнено. Проверены отказ другим ролям, замена cookie, фильтры и порядок журнала. |
| Интерфейс | Переключение аккаунта, журнал аудита, карточки, журнал инструментов, память и навигация на узком экране. | Выполнено. Текст дополняет цвета резерва. Чат показывает вызовы инструментов, статусы и модель из API. |
| Проверка | PostgreSQL, Alembic, Ruff, ESLint, сборка и Chrome. | Выполнено. Прошли 28 тестов, сверка схемы, линтеры и сборка. Проверены основные сценарии на 1440 px и вёрстка на 390 и 320 px. |

Общий журнал аудитора требует роли руководителя. Правила чтения истории отдельных партий и заданий сохранены. Переключатель использует штатный API входа. Сценарий SSE проверен с задержанным fake-провайдером на локальном сервере, чтобы успеть остановить поток в Chrome. Остатки, роли, история и изменения в этой проверке шли через PostgreSQL.
