# План автоматических тестов CandleFlow

Проект сохраняет складской учёт, API и ассистент из предыдущих этапов.

| Этап | Критерии приёмки | Результат |
| --- | --- | --- |
| Изоляция | Отдельная PostgreSQL-база с миграциями, fake LLM и запрет внешних сетевых запросов в тестах | Выполнено. PostgreSQL обязателен для интеграционных тестов. Внешние DNS и TCP подключения Python блокируются. HTTP-сервисы подменяются локальными транспортами. |
| Покрытие | Все сценарии раздела 7, включая ошибки провайдера, конкурентное подтверждение и восстановление после ошибки Code Interpreter | Выполнено. Проверены 429, 500, 503, сетевой таймаут и общий дедлайн. На 400 и 422 резервная модель не вызывается. |
| Прогон | Полный pytest на PostgreSQL, Ruff, ESLint и документированный запуск | Выполнено. Прошли 43 теста, Ruff, ESLint и сверка Alembic. |

Тесты проверяют складские остатки и движения через PostgreSQL. Вызовы модели воспроизводятся fake-провайдером или HTTP-ответами в памяти. Code Interpreter проверен на ошибке выполнения и сбое скачивания, в обоих случаях тот же диалог принимает следующий запрос.
