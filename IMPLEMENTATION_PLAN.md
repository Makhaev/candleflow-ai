# План реализации CandleFlow

Исходное состояние: в рабочей папке был только PDF задания. Git-репозиторий инициализирован локально. PDF сохранён в рабочей папке.

| Этап | Критерии приёмки | Результат |
| --- | --- | --- |
| Учётное ядро | Миграция PostgreSQL, FIFO, частичный резерв, блокировки, расход и возврат, RBAC, аудит, API, демо-данные | Выполнено. Тесты на реальном PostgreSQL, включая конкурентный резерв. |
| Доставка отчётов | Мок маркировки, атомарная запись отчёта, Redis/Celery, повторные попытки, защита от дублей | Код и тест повторной доставки готовы. Интеграционный запуск Redis/Celery в Compose требует Docker. |
| Ассистент | SSE, прерванные ответы, инструменты, подтверждение с проверкой роли, резервная модель, память, псевдонимы, Code Interpreter | Демо-сценарии и адаптер готовы. Пройдены проверки доступа, отказов, памяти, псевдонимов и файлов. Живой вызов требует ключа. |
| Интерфейс | Реестр партий, карточки, производственные задания, чат | Выполнено. ESLint, TypeScript и Vite прошли. Сценарий проверен в Chrome. |
| Сдача | README, REVIEW, 10+ эталонных вопросов, отчёт, видео, репозиторий GitHub | Локальные материалы готовы. 12/12 машинных проверок. Публикация требует доступа к GitHub. |

Допущения: FIFO по дате поступления и номеру партии. Одно изделие и рецепт на задание. Валютные курсы демонстрационные. Даты учёта ведутся по Москве, технические отметки — в UTC. Дефицит зафиксирован отдельным статусом. Отмена доступна до запуска. При недостатке сырья для завершения вся операция откатывается.

Ограничения среды: ключ OpenAI не предоставлен. Схема проверена PostgreSQL 18. Сквозной запуск Compose не проверен, так как здесь нет Docker. Псевдонимы покрывают известные справочнику имена и типовые варианты написания, произвольные имена в свободном тексте покрываются частично.
