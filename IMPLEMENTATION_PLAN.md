# План реализации CandleFlow

Базовая версия сохранена в Git. Исходный PDF остался в рабочей папке. Оба новых вложения содержат одинаковые уточнения.

| Этап | Критерии приёмки | Результат |
| --- | --- | --- |
| Учёт и курсы | Миграция, HTTP-мок курсов, дата котировки, черновик, FIFO, списание при запуске, возврат в исходные партии и атомарный перерасход | Выполнено. На отдельной PostgreSQL-базе проверен переход со схемы 0002 для запущенного задания и задания с дефицитом. |
| Асинхронный API и интерфейс | AsyncSession, серверный RBAC, карточки, отдельные операции создания черновика и планирования | Выполнено. В Chrome проверены поступление, дата курса, черновик, планирование, запуск и завершение. |
| Ассистент | Контракты инструментов, pending_actions, явная смена модели, остановка, изоляция памяти, проверка числовых значений | Выполнено в деморежиме. В Chrome проверено подтверждение создания задания и сохранения предпочтения. Живой вызов требует API-ключа. |
| Проверка и сдача | PostgreSQL, Ruff, ESLint, сборка, эталонный прогон, README, видео | 22 теста и 12 из 12 эталонных сценариев прошли. Линтеры и сборка прошли. YAML Compose проверен, запуск контейнеров требует Docker. |

FIFO сортируется по дате поступления и номеру партии. Дефицит хранится через потребность и резерв компонентов запланированного задания. Физический остаток включает все партии, свободный остаток рассчитывается только по принятым партиям. Даты учёта ведутся по Москве, технические отметки в UTC.

Маскирование покрывает имена из справочников и типовые варианты написания. Неоднозначное совпадение обезличивается без восстановления имени. Произвольные имена в свободном тексте покрываются частично. Валидатор чисел сравнивает числовые литералы с результатами инструментов и журналом Code Interpreter.
